## 技术改进

### 1. 代码组织
- 前端: `/services/` - API调用服务层
- 后端: `/src/services/` - 业务逻辑服务层
- 后端: `/src/controllers/` - HTTP请求处理层
- 后端: `/src/routes/` - 路由定义层

### 2. 数据流向
```
前端页面 → 前端Service → HTTP请求 → 后端路由 → 后端控制器 → 后端服务 → 数据库
```

### 3. 开发规范
- 新增API时需同时创建前后端服务方法
- 控制器只负责HTTP层面的处理
- 业务逻辑统一在服务层实现
- 数据验证在服务层和控制器层双重验证
