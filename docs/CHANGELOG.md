### 升级路径

**从 v1.x 升级到 v2.x**

1. 备份现有数据
2. 更新数据库结构
3. 迁移配置文件
4. 测试功能完整性
5. 部署新版本

**升级注意事项**

- v2.0.x 包含重大架构变更
- 需要重新配置环境变量
- 建议在测试环境先行验证
- 升级前务必备份数据
